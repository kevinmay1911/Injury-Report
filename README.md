# Injury Report (APB Form 045)

A fill-in app for the Airport Police Division Injury Report. It produces the completed Word form, including the ID barcode scan, dictation, photo attachments and the supervisor signature.

- Everything runs in the browser. Report data is never uploaded. Drafts are saved only on the device, and only when "Save draft" is clicked.
- Dictation uses the browser's speech service. In Chrome and Edge, that sends the audio to Google or Microsoft.
- Install it from the browser: Share → Add to Home Screen (iPhone), or ⋮ → Install app (Android, Chrome or Edge on a computer).
